Data Engineering & Modeling (OLAP)

  • Architected multi-source ingestion pipelines using PySpark, Matillion, and Boomi (CDC, watermark extracts, SaaS APIs, flat files) into Amazon Redshift, decoupling batch and near-real-time streaming via Amazon SQS for automated staging, deduplication, cleansing, and SQL business transformations.
  • Designed enterprise star and snowflake dimensional models, and developed LookML semantic models and Explores for core supply chain metrics (inventory turns, dock-to-stock cycle times, order fill rates, freight spend) with optimized datagroups and PDT lifecycle policies.
  • Implemented reverse-ETL pipelines syncing curated data back into Salesforce and Zoho, and partnered with cross-functional stakeholders (Operations, Sales, Finance) to deliver executive Looker dashboards standardizing KPIs across departments.

Backend & Middleware

  • Architected enterprise-grade serverless REST APIs and asynchronous order ingestion middleware using AWS API Gateway, Lambda, SQS FIFO, and Step Functions (Saga pattern), reliably fanning out multi-channel B2B/B2C orders to legacy ERP, WMS, and inventory distribution systems.
  • Engineered a distributed DynamoDB caching layer with SHA-256 payload fingerprinting and native TTL eviction, cutting primary database load by 30–50%.
  • Sustained 99.9% transaction completion through idempotent request handling, API Gateway throttling, DLQ redrive policies, exponential backoff, and circuit breakers.
  • Developed a high-concurrency Available-to-Promise (ATP) inventory reservation microservice using atomic conditional writes and distributed locks to prevent overselling.
  • Implemented a dual-engine search strategy combining Elasticsearch with SQL Server for sub-second search across millions of historical orders and invoices.

Database Systems (OLTP)

  • Owned OLTP database architecture and administration running mission-critical order-to-cash operations across pricing, rebates, commissions, and ERP/WMS/TMS integration feeds.
  • Architected the enterprise pricing engine in SQL Server, resolving sales-rep overrides, customer contract pricing, commodity pricing, COGS, and discount layers into real-time customer–item–DC prices via ACID-compliant T-SQL procedures.
  • Scaled the pricing API to sustain 100,000–200,000 executions/min at sub-100 ms latency with zero deadlocks under heavy concurrent load.
  • Modeled SCD Type 2 temporal pricing for point-in-time auditability, and engineered PriceIQ statistical pricing using IQR outlier fencing and skew-adjusted distribution analysis to intelligently price custom setups.
  • Built the vendor rebate calculation platform, sales commission payroll, and WMS/TMS activity-based incentive payroll.

Database Administration & Reliability (OLTP & OLAP)

  • Eliminated high-frequency lock-conversion deadlocks, write skew, and reader–writer blocking across high-throughput OLTP workloads by pairing targeted locking hints (UPDLOCK, HOLDLOCK, ROWLOCK) with deterministic UPSERT ordering and tuning Read Committed Snapshot Isolation (RCSI).
  • Resolved tempdb spills, parameter sniffing, and bookmark lookups through execution plan profiling, memory grant tuning, composite clustered/covering index redesigns, and table partitioning.
  • Automated enterprise maintenance, index defragmentation, and statistics via Ola Hallengren on SQL Server Agent, administered Always On Availability Groups (HA/DR), and tuned CDC replication.
  • Optimized Amazon Redshift storage architectures (KEY/ALL/EVEN distribution, sort keys, AZ64/ZSTD compression), WLM parameter queues, materialized views, PII data encryption, RBAC, and CloudWatch performance alarms.

Cloud Architecture & Modernization

  • Architected and provisioned an enterprise-scale, fault-tolerant AWS cloud foundation spanning multi-AZ VPCs, API Gateway, Lambda, Step Functions, SQS FIFO, DynamoDB, and Amazon Redshift.
  • Deployed a secure, auto-scaled internal application tier on AWS (EC2 in multi-AZ VPCs, Auto Scaling, hardened security groups, Route 53, Apache HTTPD reverse proxies) with automated open-source TLS rotation.
  • Engineered an event-driven Master Data Management (MDM) ecosystem across Zoho, establishing governed golden records for customer, item, and supplier entities with automated webhook and message-queued distribution to tier-1 ERP, WMS, and TMS systems to eliminate synchronization lag and discrepancies across warehouse fulfillment and freight routing networks.

DevOps & Infrastructure

  • Established end-to-end operational reliability, automated maintenance, and proactive infrastructure observability across distributed cloud microservices and database clusters.
  • Automated enterprise SQL Server maintenance, index defragmentation, and statistics updates using Ola Hallengren orchestrated via SQL Server Agent.
  • Built robust monitoring and alerting in SolarWinds (waits, blocking, resource pressure) and AWS CloudWatch (disk spill, CPU utilization, concurrency metrics).
  • Authored custom T-SQL health audit scripts, enforced least-privilege RBAC, and implemented resilient fault-tolerance mechanisms including automated Dead-Letter Queue (DLQ) redrives, exponential backoff, circuit breakers, and zero-downtime automated TLS certificate rotations.

Generative AI & Web Applications

  • Integrated Google's Model Context Protocol (MCP) server in Looker, exposing curated semantic definitions, Explores, and supply chain KPIs to generative AI agents to enable natural-language-to-SQL querying and prompt-driven analytical dashboard generation.
  • Engineered high-throughput, asynchronous FastAPI backend microservices with strict Pydantic schema validation, standardizing departmental custom data capture and preventing operational data corruption across downstream pipelines.
  • Delivered responsive, high-performance web applications and internal portals featuring seamless API integrations and granular role-based access control.
