  • Backend, Middleware & Telemetry: Scaled enterprise event telemetry ingestion and distributed middleware integrations across heterogeneous systems, sustaining high-volume event throughput with low-latency API response times and zero data loss, by engineering non-blocking Python/FastAPI REST APIs with asyncpg connection pooling, building AWS Lambda & Boomi iPaaS integration layers, and designing relational event stores with structured telemetry schemas.

  • Database Administration & Reliability (OLTP & OLAP): Maintained high-availability database operations and optimized query efficiency across hybrid multi-database clusters (PostgreSQL, SQL Server, Amazon Redshift, Aurora), significantly reducing P95 query execution latency and eliminating system deadlocks, by implementing multi-AZ failover and automated disaster recovery, structuring indexing/vacuum maintenance routines, and performing execution plan profiling with fine-grained lock tuning.
  • Cloud Architecture & Modernization: Modernized legacy on-premises infrastructure into an elastic, event-driven AWS cloud platform, reducing infrastructure overhead and completing migrations with zero cutover downtime across enterprise-scale data assets, by architecting cloud topologies leveraging Amazon Redshift, AWS Glue ETL, Lambda, Athena, S3 data lake tiers, DynamoDB, RDS Aurora, and containerized ECS workloads.
  • DevOps, Quality & Infrastructure: Accelerated release velocity and reinforced production reliability across distributed message-driven services, dramatically shortening deployment cycle times while achieving high test coverage and zero regression escapes, by orchestrating containerized workloads on Docker/EKS/ECS, provisioning Kafka and RabbitMQ event brokers on Linux, and establishing GitHub Actions CI/CD pipelines with automated Pytest, Node.js/JSDOM, ESLint, and Stylelint quality gates.
  • Full-Stack & Generative AI Web Applications: Delivered responsive Progressive Web Apps (PWAs) with interactive 3D visualizations and conversational AI capabilities, achieving ultra-low time-to-first-token (TTFT) streaming latency and high platform availability, by engineering asynchronous FastAPI microservices, streaming Amazon Bedrock LLM inference over Server-Sent Events/WebSockets, rendering Three.js GPU-accelerated graphics, and developing zero-dependency ES module frontends.
